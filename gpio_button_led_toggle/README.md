# タクトスイッチで LED をオン／オフ（オルタネイト動作）

タクトスイッチを 1 回押すと LED が点灯し、もう 1 回押すと消灯するプログラムです。
ボタンの検出には割り込み（`GPIO.add_event_detect`）を使い、チャタリングは `bouncetime=200` ミリ秒で防いでいます。

## ファイル

- `gpio_button_led_toggle.py`: プログラム本体（コメントは中国語・日本語・英語）

## 接続

| 部品 | GPIO（BCM） | ピン番号 | 備考 |
|---|---|---|---|
| LED | GPIO18 | 12 | 電流制限抵抗を直列に入れる |
| タクトスイッチ | GPIO26 | 37 | もう片方は GND。内部プルアップを使用 |

## 実行方法

```bash
python3 gpio_button_led_toggle.py
```

終了するときは `Ctrl+C` を押してください。終了時に GPIO の設定を初期化します。
