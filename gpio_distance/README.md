# 距離センサー（SHARP GP2Y0A02）＋ ADコンバータ（MCP3208）

SHARP 製の赤外線距離センサー GP2Y0A02 のアナログ出力を、AD コンバータ MCP3208 で読み取り、SPI 通信でラズパイに取り込んで距離 [cm] を表示するプログラムです。

## ファイル

- `distance.py`: 授業で配布されたサンプルプログラム（電圧と距離を 1 秒ごとに表示）

## 接続

- GP2Y0A02 の出力 → MCP3208 の CH0
- MCP3208 → ラズパイの SPI0（CE0）
- 基準電圧: 3.3V

## 準備

1. 距離センサー＆AD コンバータの回路を組む
2. ラズパイの SPI 通信機能を有効にする（`sudo raspi-config` → Interface Options → SPI）
3. Python が「SPI 機能が使えない」とエラーを出したら、次を実行する

```bash
sudo apt install python3-spidev
```

## 実行方法

```bash
python3 distance.py
```

## 補足

- センサーの測定範囲はおよそ 10cm〜80cm
- このプログラムでは、電圧が 0.5V〜3.0V の範囲外（10cm 未満や 60cm 以上）のときは距離 0 を表示する
- 距離は `27.22 / V^1.2027` の近似式で計算している
- 元ファイルの日本語コメントは文字化けで `?` になっている
